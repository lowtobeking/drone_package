# 电调(PWM)校准 + QGC 走以太网 —— 排障与流程（2026-07-31 趟出来的）

> 本台架 ZeroOne X6 Air+(PX4 v1.16) + One PMU(DroneCAN) + Orin NX。8 台机会撞同样的坑，照此走。
> 关联：`真机安全参数配置单_QGC.md`、`tools/mav_relay.py`、`tools/fc_configure.py`。

## 0. 先纠正一个认知：电调是 **PWM 400Hz，不是 DShot**
实读参数坐实：`PWM_MAIN_TIM0/1/2=400`（正值=PWM Hz；DShot 是负数编码）、`PWM_MAIN_MIN/MAX/DIS`
模拟脉宽端点在生效、`DSHOT_CONFIG` 不存在。**PWM 电调必须校准**（DShot 才不用）。

## 1. 症状：解锁后部分电机怠速不转
- 现象：解锁怠速时有电机不转，推油门才转；但 **actuator test 里 4 个都均匀转**。
- 🔑 **actuator test 4 个都转 ⇒ 电机/电调物理都好**，问题在"怠速那个很低的值"。分两种，用 actuator test
  逐个慢慢拨、看各自起转百分比区分：
  - 起转点明显更高的那个 → 电调低端没校准 → 做**电调校准**（下节）。
  - 4 个起转点差不多、只是怠速卡在下面 → **抬怠速**（§3）。

## 2. 电调校准（PWM，QGC 引导式最安全）
**🔴 桨必须拆。FC 靠 USB 供电（这样飞行电池能拔出来）。**

拦路虎 = **`UAVCAN_SUB_BAT=1`（DroneCAN 电池）**：PX4 只要"配了电池源"就拒绝 ESC 校准、一直报
**"断开电池"**（哪怕你物理拔了电池也没用——清不掉这个**配置**；官方 issue #24401 同因）。

流程：
1. QGC Parameters：`UAVCAN_SUB_BAT` = **0** → **重启飞控**（此参数开机才生效）。
2. QGC → Power → **Calibrate ESC**（这次能启动，走**定时式**校准）。
3. 按提示**插上飞行电池** → 电调上电听满油门→学 max → 自动落到最小油门→学 min → "校验完成"。
4. **`UAVCAN_SUB_BAT` 改回 1 + 重启**（恢复电池监控，飞行必需）。

## 3. 抬怠速修"某个电机怠速不转"（校准后仍剩的那种）
校准后若仍有 1 个不转，那是**怠速(1100µs)偏低、卡在它起转点下面**（静摩擦/齿槽），不是端点问题。
- **4 个 `PWM_MAIN_MIN` 必须统一抬**：实测**只改坏的那一个不生效、4 个都改同值才行**
  （PX4 把 4 电机怠速当一组）。本台架抬到 **1115** 全转；**建议 ~1130 留余量**。
- ⚠️ **别在校准前抬怠速**：未校准的 4 电调曲线不一，抬怠速会掩盖问题、飞起来推力不对称→翻。
  **校准后**曲线一致，统一抬怠速才安全。
- ⚠️ **1115 是无桨临界值，装桨起转更难（负载+惯量）**。**首飞前地面装桨解锁一次、盯 4 桨都稳转再起飞**；
  不够继续往上抬。

## 4. QGC 走以太网（USB 参数拉不全时）
USB 串口丢包 → QGC "无法检索完整参数集"。治法走以太网，但 QGC v5.0.8 以太网 UDP 链路**只监听、
不主动呼叫飞控**，飞控又只广播+单播给 Jetson、不发仿真机 → 自己连不上。**用 `tools/mav_relay.py` 中转**。

前置：①Jetson `DOCKER-USER` 加双向 ACCEPT(wlP1p1s0↔eno1)；②仿真机 `sudo ip route add
192.168.77.0/24 via <JetsonWiFiIP>`；③**拔飞控 USB 线**（否则 QGC 抢 USB 口不走以太网）；
④Jetson 上 `setsid nohup python3 tools/mav_relay.py &`。详见 `tools/mav_relay.py` 头注释。
- 台架图省事也可直接用 USB（拉不全但改单个参数/actuator test 够用）。

## 5. 附：手势解锁突然失效
`MAN_ARM_GESTURE=0` → 手势(左杆下+偏航右)解不了锁。根因：**QGC 里配 CH7 解锁开关会自动把
`MAN_ARM_GESTURE` 置 0，取消开关后 QGC 不帮你改回**。改回 **1** 即恢复（不用重启）。
另：解锁后没推油门起飞、几秒自动上锁 = `COM_DISARM_PRARM` 超时，正常。
