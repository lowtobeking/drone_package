# 真机手动首飞：调参过程与日志诊断记录

> 记录时间：2026-08-05
> 阶段：真机**手动首飞**（第一次离地至手动飞稳）。目标仅为把飞机手动飞稳，offboard / 动捕 / 编队尚未介入。
> 用途：真机平台搭建与调试的正式记录；其中"日志分析方法"与"平台就绪"结论可供后续报告 / 论文（真机验证章节）取用。

## 1. 真机平台

| 部件 | 型号 / 规格 |
|---|---|
| 飞控 | ZeroOne X6 Air+（FMUv6X 架构，PX4 **v1.16.0**） |
| 机架 | X500 V2（500 mm 轴距，10 寸桨，`SYS_AUTOSTART=4019` quad-X） |
| 电调 | **PWM**（非 DShot），无遥测 |
| 电池 | 4S（大：5300 mAh；小：4000 mAh） |
| 地面站链路 | QGC ← **3DR 数传**（CP2102/COM5，纯无线）→ 飞控 TELEM1 |
| 遥控 | 穿越机 Mode2，油门不回中、最下为 0，手势解锁 |

手动阶段为"裸飞控 + 3DR + 遥控"，不含机载电脑（Jetson）。

## 2. 调参过程与关键参数决策

| 参数 | 决策 | 依据 / 说明 |
|---|---|---|
| `EKF2_BARO_CTRL` | vision-only → **Enabled** | 原为动捕用的 vision-only（关 baro），导致 Altitude 切不进（`No valid altitude estimate`）。开 baro 后 Altitude 可用。**⚠️ 上动捕 offboard 必须改回 vision-only**（两套高度源不可混） |
| `SENS_BOARD_ROT` | 保持 **0** | 飞控外壳箭头物理朝左，但 `ROT=0` 下手动飞行俯仰/横滚全跟手 ⇒ IMU 逻辑前向已对齐机架机头（出厂固件已补偿）。误设 `YAW_270` 起飞即翻（与正确值差 180° → pitch/roll 双反号正反馈）。**结论：朝向已正确，箭头仅为外壳丝印** |
| `PWM_MAIN_MIN` | 四路统一抬高 | 修复起飞侧飘/向右倒的 roll-pitch 电机不对称（详见 §4.1） |
| `MPC_THR_HOVER` | 0.5（默认）→ **0.32**（大电池标定值） | 由 Altitude 悬停日志的在线估计器 `hover_thrust_estimate` 标定（详见 §4.2） |
| `MPC_THR_MIN` | 0.30 → **0.12** | `THR_MIN` 误等于 `THR_HOVER`，推力下限卡在悬停点导致 Altitude 降不下来（详见 §4.3） |
| `MPC_Z_VEL_MAX_UP` / `_DN` | 最小 → **2.0 / 1.5** m/s | Flight Behavior 三滑块曾全调至最小，导致"推油门延迟极高"；回调至合理值 |
| `MPC_XY_VEL_MAX` | → **3.0** m/s | 7×8.5 m 小场地够用 |

### Altitude 模式操作认知（穿越机飞手易误区，记录备查）
- Altitude 油门 = **爬升率**，非推力：**中位 = 定高**（地面即"趴着不动"），故"推一半没动静"属正常；起飞须果断推过中位（~70%），降落须收到中位以下。
- Altitude 不自动着陆上锁，触地后需手动收油门 + 上锁，或切回 Stabilized。
- Stabilized（油门直通推力，0 级外环）手感"像穿越机"；Altitude（垂直走速度环+高度保持）手感"像普通四旋翼"——同一架机、两种控制策略。

## 3. 日志分析方法（pyulog）

用 `pyulog` 提取 `.ulg`，围绕以下指标分析：
- **模式/解锁时间线**（`vehicle_status.nav_state / arming_state`）
- **悬停段识别**（离地 & 低垂直速 & 低水平速）
- **悬停油门估计**（`hover_thrust_estimate`，PX4 在线估计器）
- **电机对称性**（`actuator_motors.control[0..3]`，按 CW/CCW 分组）
- **力矩配平偏置**（`vehicle_torque_setpoint`，稳态应 ≈0）
- **姿态跟随**（`vehicle_attitude` 实际 vs `vehicle_attitude_setpoint` 期望）
- **机体系漂移速度**（`vehicle_local_position.vx/vy` 经航向旋转到 body-frame 的前向/右向分量）

### 3.1 关键方法学：松杆分析（区分"飞机固有偏置" vs "飞手操控"）
悬停时飞手常持续打杆修正，**姿态/漂移的均值里混入了飞手指令**，不能直接当作飞机固有偏置。方法：**筛选某轴摇杆 ≈0（松杆）的帧**，只看这些帧的力矩 / 漂移 / 角速率——
- 松杆时力矩仍偏、飞机仍朝某方向加速 ⇒ **飞机真有固有偏置**（飞控在反压）
- 松杆时力矩 ≈0、飞机不动 ⇒ 之前的偏差是飞手打杆造成的，无固有故障

本记录中的 yaw 偏置（§4.4）与左飘（§4.5）均由此法定性。

### 3.2 方法学教训（避免误判）
"悬停段"判据通常含"水平速度 < 阈值"过滤，**会天然滤掉漂移帧**——只看悬停段会误判"飞机不飘"。**判断水平漂移必须用松杆分析看 body-frame 漂移速度**，不能依赖悬停段统计。（本次曾据悬停段误判"大电池不飘"，后经松杆分析翻案，见 §4.5。）

## 4. 诊断结论（均有日志数据佐证）

### 4.1 roll/pitch 电机对称性：已修复 ✅
首飞初期严重侧飘（左脚架先离地、向右倒），根因为 `control[2]`（前左）0.41 / `control[3]`（后右）0.22 差约 50% + roll/pitch 力矩偏置。经 `PWM_MAIN_MIN` 一致性核查 + 拆桨 Motor Test 修复。

验证（log_65 / 69 / 70）：姿态跟随近乎完美——实际 roll/pitch 均值 ≈0、std < 1.3°，与期望几乎重合；roll/pitch 力矩偏置 ≈0；`control[2]/[3]` 拉平。

### 4.2 悬停油门 `MPC_THR_HOVER` 标定 = 0.32（大电池）
`hover_thrust_estimate` 仅在 ALTCTL/POSCTL 下运行（STAB 下为 nan，故 log_65 无法标定）。ALTCTL 悬停段稳定收敛：

| 日志 | 电池 | 悬停时长 | `hover_thrust_estimate`（均值/末值/std） |
|---|---|---|---|
| log_69 | 大 | 43 s | 0.318 / 0.328 / 0.007 |
| log_70 | 大 | 26 s | 0.339 / 0.335 / 0.003 |

⇒ 大电池悬停油门 ≈ **0.32–0.34**（默认 0.5 明显偏高）。小电池更轻、悬停油门更低（log_74 约 0.2 量级，但贴地估计不稳）。**`THR_HOVER` 应随电池配置调整**，或依赖 PX4 在线估计器每次自适应。

### 4.3 Altitude "油门拉到底也降不下来" = `MPC_THR_MIN` 卡死
根因：`MPC_THR_MIN` = 0.30 恰好等于 `MPC_THR_HOVER` = 0.30。降落需推力降至悬停以下，但推力下限卡在悬停点，飞控产生不了下降所需的更低推力。

数据铁证（log_69，ALTCTL 内油门拉低 throttle < −0.6）：

| 量 | 值 |
|---|---|
| 油门 | mean −0.87（最低 −0.99） |
| 期望下降率 `vz_sp` | **+0.89 m/s**（飞控确实收到下降指令） |
| 实际下降率 `vz` | **+0.04 m/s**（几乎不降） |
| 推力 setpoint（z） | −0.276（贴着 `THR_MIN`=0.30，压不下去） |

log_69 最后被迫切 STAB 才降落（STAB 油门直通推力，绕过卡点）。**修复：`MPC_THR_MIN` → 0.12。规则：`THR_MIN` 必须明显小于 `THR_HOVER`。**

### 4.4 yaw 偏置：稳定复现，疑似电机/机架几何
现象：CW 电机组（m3 前左 / m4 后右）比 CCW 组（m1 前右 / m2 后左）整组多出力，`yaw` 力矩持续负偏置。

| 日志 | CW−CCW 组差 | yaw 力矩（松杆） |
|---|---|---|
| log_65 (STAB) | +0.108 | −0.054 |
| log_69 | +0.100 | −0.050 |
| log_70 | +0.080 | −0.040 |
| log_73/74/75 | +0.069 / +0.111 / +0.100 | −0.034 / −0.057 / −0.057 |

**松杆判据**（log_65，yaw 杆=0，n=71）：yaw 力矩仍 −0.054、组差仍 +0.108、飞机 yaw 率 ≈0 ⇒ 是飞机固有自转趋势、飞控在反压，非飞手打舵。量级 ~5% 满量程，不致命。

### 4.5 固有左飘：松杆分析坐实，与电池无关
**排查曲折（已在 §3.2 记为方法学教训）**：初期据"悬停段"统计误判"大电池不飘、换小电池才飘"，并沿"配重/CG"方向排查数轮；后用松杆 body-frame 漂移速度分析翻案。

松杆（roll 杆=0）机体右向速度 `v_right`（>0 右 / <0 左）：

| 日志 | 电池 | 松杆 `v_right` | 方向 |
|---|---|---|---|
| log_69 | 大 | −1.06 m/s | 左 |
| log_70 | 大 | −0.23 → −1.06 m/s | 左 |
| log_75 | 小 | −0.70 m/s（另 `v_fwd` −0.66，即左后） | 左（后） |

**三份日志（大/大/小电池）松杆时均往左飘、且松杆后持续加速。** 结合：
- 静止水平时 QGC roll/pitch = 0 ⇒ 排除**水平校准**偏差
- 换回大电池照飘 ⇒ 排除**电池 / CG**
- 松杆姿态 ≈水平却持续水平加速 ⇒ 合推力有水平分量 ⇒ **推力矢量不垂直**（CG 偏移配平后姿态水平就不该有净水平力）

### 4.6 统一根因（推断）：某电机推力线不垂直
左飘（§4.5）与 yaw 偏置（§4.4）两个"持久、与电池无关"的现象，可由**单一物理根因统一解释**：某个电机安装不垂直——推力的**水平分量 → 左飘**、**切向分量 → yaw 偏置**。目视难辨（几度倾斜肉眼不可见）；PWM 电调无遥测，无法取单电机数据。建议排查：电机垂直度/共面性、机臂变形、电机座松动；或交换法（换/对调桨再飞松杆对比）。

## 5. 与后续 offboard / 论文的关系

- **左飘与 yaw 偏置对 offboard 非阻塞**：offboard 下位置环（MPC 位置闭环 + PX4 速度环 + 动捕位置）会持续纠正水平漂移；手动 Altitude 无水平位置环才暴露。根因仍占用少量控制余量并留小稳态偏置，仅极限工况需留意。用户拍板先记为已知项、带着推进。
- **配置切换**：进入 offboard 前 `EKF2_BARO_CTRL` 须改回 vision-only；`THR_HOVER` / `THR_MIN` / 速度限幅在 offboard 垂直方向沿用。
- **对论文**：本记录直接价值在"真机平台已搭建并手动飞稳"的佐证，以及 §3.1 松杆分析方法学；论文核心（编队 MPC 的速度环滞后 τ 诊断）所需的**编队 offboard 真机数据**仍待后续采集，不由本阶段提供。
