# 飞场对接问题清单（多机 MPC 编队试飞前）

> 拿到飞场信息前，动捕链路 / OFFBOARD 闭环 / 渐进放飞都动不了 —— 这份是解开飞行相位的**关键路径**。
> 关联：`真机推进待办.md`（B 节）、`无桨台架验证清单.md`（阶段 3）、`How_to_fly_with_control.md`（飞场原始文档）。
>
> 图例：🔴 硬阻塞（拿不到就动不了动捕链路）；🟡 重要但有 fallback。

**我方设备**：ZeroOne X6 Air+ 飞控（PX4 v1.16）+ Nvidia Orin NX 机载电脑；
链路走**以太网 + uXRCE-DDS**；定位用飞场**动捕 + VRPN**。

---

## 一、网络 / IP 🔴（配 XRCE 链路必需）

1. 飞场网络网段是 **10.41.10.0/24** 吗？网关是 `10.41.10.1` 还是 `10.41.10.254`？
2. 给我方**飞控**和**机载电脑(Orin NX)**各分配哪个 IP？**静态还是 DHCP**？
3. 地面站(QGroundControl)接在**同一网段**吗？（决定要不要跨网段转发）

## 二、动捕 / VRPN 🔴（定位闭环必需）

4. 动捕系统品牌（OptiTrack / Vicon / NOKOV / 其它）+ 用什么软件？
5. **VRPN server** 跑在哪台机、IP、端口（默认 3883）？
6. **刚体命名规则**？（我方桥默认订阅 `/vrpn_mocap/<刚体名>/pose`，名字要对齐；接错会**静默无数据**）
7. VRPN 输出**频率**能到多少？（我方要 **≥50 Hz**）
8. 动捕输出的**坐标系约定**：ENU 还是 NED？**原点在场地哪个位置、朝向哪**？
   （决定坐标变换正确性，**最容易错的一环**）
9. **标定体积的实际尺寸**（不是场地尺寸，是动捕能稳定跟踪的范围）？（决定围栏/场景活动半径）

## 三、桥 / 软件对齐 🟡

10. 飞场文档提到的 `px4_mocap_bridge` 有**仓库地址 / 话题配置**吗？我方已有自研
    `mocap_bridge_node`（已实测通过 ENU→NED 注入，见 `无桨台架验证清单.md` 阶段 3），
    确认**用哪一个**、话题接口是否一致？

## 四、数传 / 其它 🟡

11. 我方数传是 **3DR 433MHz SiK 电台**，飞场认可吗？（飞场文档写的是 ESP32，433 频段有无冲突/管制？）
12. 机载电脑取 VRPN 数据要连飞场网络，对 companion **出网 / 网络隔离**有无要求？

---

## 最关键两项

- **8（坐标系/原点）**：错了整个位置闭环是歪的。
- **9（标定体积）**：决定 `IN_*` 场景与围栏值能不能定死（现值是按 7×8.5 m 推的保守估计）。
