# 真机手动首飞调参记录（2026-08-03）

ZeroOne X6 Air+（PX4 v1.16）第一次真机手动试飞的连接、配置与调参全过程，供后续复飞及其它机复用。

> **阶段说明**：手动试飞 = 裸飞控 + 遥控 + 3DR 数传，**飞机上不装 Jetson**。Jetson / XRCE / offboard / 动捕是后续阶段，与本阶段无关。

---

## 1. 地面站连接（QGC ← 3DR 数传 → 飞控 TELEM1）

纯无线，不经 Jetson、不用以太网桥。

- 3DR 数传**地面端芯片 = CP2102**（USB VID_10C4 / PID_EA60）。
- **坑**：Windows 上 CP2102 驱动可能缺失，表现为设备管理器「其他设备」里带感叹号、问题代码 **28（驱动未安装）**，**不生成 COM 口**，QGC 无口可连。
- **解法**：装官方 **Silicon Labs CP210x Universal Windows Driver**（silabs 直链下 zip → 解压 → 设备管理器「更新驱动 → 浏览到解压目录」，或管理员 `pnputil /add-driver silabser.inf /install`）→ 出现 COMx。
- 连上后 QGC 会自动占用该 COM 口。确认真连上：QGC 主界面地平线、电池、姿态实时刷新。

**遥控**：穿越机 Mode2，左手油门**不回中**、最下 = 0；手势解锁（stick gesture）。
> ⚠️ 日志中出现多次 `Manual control lost`（regained after 42~75s）——RC 链路稳定性待查（接收机协议 / 包速率 / 天线）。

## 2. 开 baro，让 Altitude 模式可用

- **现象**：切 Altitude 报 `Critical: Switching to 'Altitude control' not possible — No valid altitude estimate`。
- **原因**：EKF2 当前是动捕用的 **vision-only**（`EKF2_GPS_CTRL=0`、baro 关），没有任何高度源。
- **改法**：`EKF2_BARO_CTRL` = **Enabled**（并确认 `EKF2_HGT_REF` 指向 Baro）→ 重启飞控 → QGC 不再报错、高度正常，Altitude 可用。
- ⚠️ **以后上动捕 offboard 时必须改回 vision-only**，两套高度源配置冲突，不可混用。

---

## 3. 电机 50% 不对称 → 侧飘修复

- **现象**：Stabilized 起飞明显向右飘、**左脚架先离地**（飞到约 1.9 m 但侧倾）。
- **日志定位**（pyulog）：稳态电机输出 `control[2]`（前左）= 0.41、`control[3]`（后右）= 0.22，**相差约 50%**，且 roll/pitch 控制力矩存在恒定偏置 → 明确的**物理不对称**（非加速度计校准问题）。
- **排查顺序**：
  1. 重心 —— 正常。
  2. 桨型号 / 对角旋向 —— 正常。
  3. `PWM_MAIN_MIN` / `PWM_MAIN_MAX` 四通道一致性 + 拆桨 **Motor Test**（同油门对比四电机转速/声音）—— **在此修复**。
- **判据**：修复后拆桨 Motor Test 四电机应一致；复飞后日志 `control[0..3]` 应拉平、力矩偏置回 0（待最终验证）。

## 4. Altitude 起飞操作要点（穿越机飞手必读）

**Altitude 的油门 = 爬升率，不是推力**（与穿越机/Stabilized 完全相反）：

| 油门杆 | 含义 |
|---|---|
| 正中位 | 零爬升率 = **保持当前高度**（地面时即趴着不动） |
| 中位以上 | 爬升（越高越快） |
| 中位以下 | 下降 |

- **从地面起飞必须果断把油门推过中点（约 70%）**，飞控自动配悬停推力 + 正爬升率 → 干脆离地；到 1~1.5 m 后油门回中位 = 定高悬停。
- **不要停在中位**（= 保持地面高度 = 不动），这是「推了油门没反应」的根因。
- `COM_DISARM_PRFLT`（默认 ~10 s）：解锁后未检测到起飞会自动上锁——一直没离地会被反复自动 disarm，属正常保护；练习嫌短可调 20~30 s。

## 5. Altitude 敏感度调参

- **现象**：能起飞后，稍推油门 → 很大 z 加速度（推重比高 + 爬升率上限默认偏大）。
- **调整方向**（QGC 参数页，一次改 1~2 个、落地改、小步试）：

| 参数 | 默认约 | 建议 | 作用 |
|---|---|---|---|
| `MPC_Z_VEL_MAX_UP` | 3 m/s | 2（别降太狠） | 杆满行程对应的爬升率，最直接 |
| `MPC_ACC_UP_MAX` | 4 m/s² | 2~3 | 限垂直加速度，爬升更绵 |
| `MPC_HOLD_DZ` | 0.1 | 0.15~0.2 | 加大中位死区，中位附近不误触发 |
| 遥控油门 expo | — | 中段加 expo | 中位平缓、两端才陡 |

> 降 `MPC_Z_VEL_MAX_UP` 过头会导致油门/爬升偏软，需在「太敏感」与「没劲」间取平衡。
