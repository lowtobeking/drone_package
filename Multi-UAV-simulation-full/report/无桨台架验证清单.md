## 现在缺什么才能往下走

| 你手上要有 | 解锁哪些项 |
|---|---|
| **只要遥控**（不用装机、不用电池） | 阶段 0 全部 —— 遥控校准、模式开关、**`RC_MAP_KILL_SW` 拨杆映射**（三个安全底线里最后一个空缺） |
| **只要电池**（不用遥控） | 电调校准、电机转向、One PMU 标定（都走 `DO_MOTOR_TEST`，不经解锁） |
| **电池 + 遥控都要** | 阶段 2 的 kill 实拨、Stabilized 试转 —— 要先解锁才看得到 kill 生效 |
| 都不要 | 传感器校准（USB 供电即可，但**必须装机后**做）；companion 侧全部（已完成） |

## 结论先行：这条链**不需要定位**，装机才是阻塞

2026-07-22 查 PX4 v1.14.3 源码确认（非推断）：

| 项目 | 需装机 | 需解锁 | **需定位** | 依据 |
|---|---|---|---|---|
| RC 校准 / 通道映射 | ❌ | ❌ | ❌ | QGC 直接读通道 |
| 电调校准 | ✅ | ❌ | ❌ | QGC 触发，上电即输出校准信号 |
| 电机转向测试 | ✅ | ❌ | ❌ | `COM_MOT_TEST_EN` 默认 1，走 `DO_MOTOR_TEST`，不经 arming |
| kill 开关实测 | ✅ | ✅ | ❌ | 要 arm 才看得到 kill 生效 |
| Manual / Stabilized | ✅ | ✅ | ❌ | `mode_requirements.cpp`：只要角速度+姿态+RC |
| ~~Altitude 定高~~ | ✅ | ✅ | ⚠️ **是** | ~~气压计够~~ —— **飞场配置 `EKF2_BARO_CTRL=disabled`，气压计被禁用，高度完全依赖动捕** |
| Position | ✅ | ✅ | ✅ | 要 `local_position_relaxed` |
| **OFFBOARD（本项目）** | ✅ | ✅ | ✅ | 2026-07-22 实测确认 |

### ⛔ `COM_ARM_WO_GPS` 必须保持 **1**（结论已随定位方案落定而更新）

飞场配置 `EKF2_GPS_CTRL=0` 彻底禁用 GPS。此时若把 `COM_ARM_WO_GPS` 设成 0
（要求 GPS lock），**将永远无法解锁**，本清单阶段 2 之后全部做不了。
原 `真机安全配置清单_FC.md` §1.8 要求设 0，那是**室外 GPS 场景**的加严项，
在动捕方案下**不适用**。

#### ⚠️ 上电顺序：**先 Jetson（等 Agent active），后飞控**

PX4 的 `uxrce_dds_client` 在 Agent 消失后**不会自动重连** —— 实测把 Agent 从手动
进程换成 systemd 服务（命令完全相同），飞控就此静默、连 MAVLink 广播都停，
等约 10 分钟无自愈，**必须重启飞控**。排查判据：

| 现象 | 含义 |
|---|---|
| `carrier=1` + `Link detected: yes` | 线材/转换模块正常，**不是物理问题** |
| ping 通但抓包只有 ARP、无到 8888 的 UDP | 客户端没在发 → **重启飞控** |
| 飞控上电后 ~10s 内 ping 不通 | 若 `BOOTPROTO=fallback` 属**正常**（先跑 DHCP）；已改 static 故现在 3s |
